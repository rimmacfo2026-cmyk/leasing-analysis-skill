# Анализ лизинга в Excel

Скилл для Codex помогает сравнивать коммерческие предложения и договоры лизинга: собирает условия из документов, строит графики платежей и готовит подробный Excel-анализ. Подходит для одного или нескольких предложений.

## Как установить и использовать

1. Скачайте репозиторий через кнопку Code → Download ZIP и распакуйте архив.
2. Скопируйте папку leasing-analysis в каталог ~/.codex/skills/leasing-analysis.
3. Перезапустите Codex, чтобы он обнаружил новый скилл.
4. Приложите предложения, договоры, графики и сведения о налоговом режиме и напишите: «Используй $leasing-analysis: сравни предложения и подготовь подробный анализ в Excel. Отметь неизвестные условия и покажи нагрузку на кассу».

Скилл учитывает аванс, график, выкуп, комиссии, страхование, скидки и доступные налоговые допущения. Он показывает, каких данных не хватает, и помогает подготовить вопросы лизинговой компании.

Результат зависит от полноты документов и применимых налоговых условий. Проверяйте договор, расчёт лизинговой компании и налоговый учёт со специалистом. Не размещайте конфиденциальные документы в публичном репозитории.

Файл скилла: leasing-analysis/SKILL.md. Личных данных и исходных документов конкретной сделки в репозитории нет.
