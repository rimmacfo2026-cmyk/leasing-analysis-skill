# Анализ лизинга в Excel

Скилл помогает сравнивать лизинговые предложения и договоры: собирает условия из документов, строит графики платежей и готовит подробный анализ в Excel.

## С какими AI-инструментами работает

Скилл можно использовать в Codex, Claude Code и других AI-инструментах, поддерживающих формат SKILL.md. В Claude и Claude Desktop его можно загрузить как пользовательский скилл. Совместимость, способ установки и создание Excel зависят от возможностей конкретного инструмента. Работа в Claude и других инструментах пока не проверялась.

## Как установить

Для Codex или Claude Code отправьте своему помощнику сообщение:

> Установи скилл leasing-analysis из репозитория https://github.com/rimmacfo2026-cmyk/leasing-analysis-skill, папка leasing-analysis.

Потребуется доступ к GitHub и возможность установки скиллов. После установки следуйте указаниям инструмента; для Codex может понадобиться перезапуск.

В Claude или Claude Desktop: скачайте папку leasing-analysis, создайте ZIP, содержащий эту папку в корне, и загрузите через Customize → Skills → Create skill → Upload a skill. Выполнение кода и создание файлов должны быть включены.

Если инструмент не поддерживает скиллы, можно предоставить ему текст файла leasing-analysis/SKILL.md как инструкцию вместе с документами. Возможность создать Excel зависит от инструмента.

## Как использовать

Приложите предложения, договоры, графики и сведения о налоговом режиме. Напишите:

> Используй скилл анализа лизинга: сравни предложения и подготовь подробный анализ в Excel. Отметь неизвестные условия и покажи нагрузку на кассу.

Скилл учитывает аванс, платежи, выкуп, комиссии, страхование, скидки и налоговые допущения. Он отмечает недостающие данные и помогает подготовить вопросы лизинговой компании.

Результат зависит от полноты документов и применимых налоговых условий. Проверяйте договор, расчёт лизинговой компании и налоговый учёт со специалистом. Не размещайте конфиденциальные документы в публичном репозитории.
