# Анализ лизинга в Excel

Скилл для Codex помогает сравнивать лизинговые предложения и договоры: собирает условия из документов, строит графики платежей и готовит подробный анализ в Excel.

## Как установить

Откройте Codex и отправьте ему это сообщение:

> Установи скилл leasing-analysis из репозитория https://github.com/rimmacfo2026-cmyk/leasing-analysis-skill, папка leasing-analysis.

Codex выполнит установку, если в вашей среде доступна установка скиллов и есть доступ к GitHub. После установки перезапустите Codex, чтобы он обнаружил скилл.

Если автоматическая установка недоступна, скачайте репозиторий через Code → Download ZIP и скопируйте папку leasing-analysis в ~/.codex/skills/leasing-analysis.

## Как использовать

Приложите предложения, договоры, графики и сведения о налоговом режиме. Напишите:

> Используй $leasing-analysis: сравни предложения и подготовь подробный анализ в Excel. Отметь неизвестные условия и покажи нагрузку на кассу.

Скилл учитывает аванс, платежи, выкуп, комиссии, страхование, скидки и налоговые допущения. Он отмечает недостающие данные и помогает подготовить вопросы лизинговой компании.

Результат зависит от полноты документов и применимых налоговых условий. Проверяйте договор, расчёт лизинговой компании и налоговый учёт со специалистом. Не размещайте конфиденциальные документы в публичном репозитории.
